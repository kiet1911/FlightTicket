# 📖 Overview

This project is a complete airline ticket booking platform that enables customers to search flights, reserve seats in real time, make online payments, and manage booking history.

The system also includes a powerful administration dashboard for managing flights, airports, aircraft, employees, customers, schedules, and transactions.
